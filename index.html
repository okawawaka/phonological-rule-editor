記法

  • 音変化: A -> B / C _ D
  • 通時的変化: A > B / C _ D（再建形: *p > b）
  • 素性行列: [+voice, -cont]（カンマまたは空白区切り）
  • 音素・記号: k, p, ∅（脱落/0）, #（語境界）, $（音節境界）
  • 環境省略: 文脈自由規則は / 以降を省略（例: A -> B）

操作

  • スロット編集: スロットをクリックして音素を直接入力、または下のパレットから素性を追加。
  • 記号切り替え: ヘッダーまたはスロット間の記号をクリックして → と > を切り替え。
  • フォント切り替え: プレビュー枠の「明朝 / ゴシック」で出力フォントを変更。
  • カスタム素性: パレットの入力欄から任意の素性名を追加。
  • エクスポート:
    • PNG コピー: クリップボードに画像を格納。
    • PNG / SVG: 画像ファイルを保存。
    • KaTeX コピー: LaTeX数式コードを格納。

ショートカット

  • ? : 操作説明の開閉
  • Esc : 操作説明を閉じる
