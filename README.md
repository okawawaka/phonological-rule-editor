# phonological-rule-editor

言語学における音韻規則（共時的規則）および音変化（通時的変化）を記述・可視化し、画像（PNG / SVG）や LaTeX 数式コード（KaTeX）として出力する Web アプリケーション。

## 機能仕様

- **入力方式**:
  - テキスト入力（例: `[+syl] -> [+nas] / _ [+nas]`、`*p > f / # _`）
  - スロットGUI（標的音 A、変化後 B、先行環境 C、後続環境 D）
  - テキストとスロットGUIの双方向リアルタイム同期
  - 全角文字（`［ ］／＿＋ー＞`）の半角自動正規化
- **記号対応**:
  - 共時的規則の矢印記号（`→`）
  - 通時的音変化の記号（`>`）および再建形記号（`*`）
- **弁別素性**:
  - 生成音韻論（SPE / Hayes 2009）に基づく主要クラス、喉頭、調音様式、舌頂音、舌背・母音、唇音、韻律素性のパレット
  - ユーザー定義のカスタム素性入力
  - 変項係数（`α`, `β`）対応
- **出力形式**:
  - PNG 画像（クリップボードコピー / ファイル保存）
  - SVG ベクター画像（ファイル保存）
  - KaTeX / LaTeX 数式コード（`amsmath` 準拠）
  - 出力フォント選択（明朝体 / ゴシック体）
- **動作環境**:
  - 依存ライブラリのビルド不要（スタンドアロン HTML / CSS / JavaScript）
  - ローカルまたは Web サーバー上で動作

## プリセット

- 英語 弾音化 (`t -> ɾ / [+syl, +stress] _ [+syl, -stress]`)
- 母音鼻音化 (`[+syllabic] -> [+nasal] / _ [+consonantal, +nasal]`)
- 語末無声化 (`[-sonorant, +voice] -> [-voice] / _ #`)
- 鼻音同化 (`[+nasal] -> [+coronal, +anterior] / _ [+coronal, +anterior]`)
- 日本語 口蓋化 (`[+coronal, -continuant] -> [+high, -anterior] / _ [+syllabic, +high, -back]`)
- 母音脱落 (`[+syllabic, -stress] -> ∅ / [+consonantal] _ [+consonantal]`)
- グリムの法則 (`*p > f / # _`)
- 母音間有声化 (`*p > b / V _ V`)
- 第二次子音推移 (`*t > ts / # _`)

## 記法仕様

| 要素 | 記法例 | 備考 |
| :--- | :--- | :--- |
| 素性行列 | `[+syl, +high]` | 角括弧内にカンマまたは空白区切りで列挙 |
| 音素・文字列 | `k`, `t`, `ɾ` | 英数字およびIPA記号 |
| 変化記号（共時） | `->` または `→` | 矢印で変化を表現 |
| 変化記号（通時） | `>` | 不等号で変化を表現（再建形: `*p > b`） |
| 環境区切り | `/` | 変化が生起する環境の指定（省略時は文脈自由規則） |
| 環境位置 | `_` または `__` | 標的音が現れる位置 |
| 語境界 | `#` | 単語境界 |
| 音節境界 | `$` | 音節境界 |
| 脱落 | `∅`, `0`, `null` | 空集合・ゼロ要素（`∅`）に変換 |

## 使用方法

1. `index.html` をブラウザで開く。
2. テキスト入力欄またはスロットGUIで規則を入力・編集する。
3. エクスポートボタン（PNG コピー、PNG 保存、SVG 保存、KaTeX コピー）を押して出力する。
4. `HELP [?]` ボタンまたは <kbd>?</kbd> キーで操作説明を表示可能。
