# 言語学 音韻規則エディタ (Phonological Rule Editor)

[![GitHub](https://img.shields.io/badge/GitHub-okawawaka%2Fphonological--rule--editor-black?style=flat&logo=github)](https://github.com/okawawaka/phonological-rule-editor)
[![License: MIT](https://img.shields.io/badge/License-MIT-black.svg)](LICENSE)

現代的で合理的な**スイス・スタイル（International Typographic Style）**による、言語学・音韻論（Phonology）・比較歴史言語学（Comparative Historical Linguistics）研究向けの高機能Web音韻規則エディタです。  
大学の講義、レポート・卒業論文・学術論文の執筆、学会発表スライドの作成に最適化されています。

外部ソフトウェアのインストールやビルドは一切不要（Zero-build / Standalone HTML5）。ブラウザを開くだけで即座に動作します。

---

## 🌟 主な機能と特徴

### 1. スイス・スタイル 2層ヘッダー構造（2-Tier Swiss Header）
- **Tier 1 (マストヘッド)**: タイトルと副題、および操作説明 `HELP [?]` を配置。
- **Tier 2 (アクション・ツールバー)**: プリセット選択、音変化記号切り替え（`→` / `>`）、高解像度エクスポート群を整然と配置。
- いかなる解像度やウィンドウ幅でもタイトルとコントロールが干渉しない、美しく堅牢なグリッド設計。

### 2. 直観的な操作と双方向リアルタイム同期
- **グラフィカル・スロットGUI**:
  標的音 ($A$)、変化後 ($B$)、先行環境 ($C$)、後続環境 ($D$) を視覚的なスロットとして直観的に直接編集可能。
- **テキスト記法との双方向同期**:
  テキスト入力欄（例: `[+syl] -> [+nas] / _ [+nas]` や `*p > f / # _`）とGUIが完全同期。全角記号（`［ ］／＿＋ー＞`）の自動正規化にも対応。

### 3. 音変化記号の柔軟な瞬時切り替え（`→` ⇔ `>`）
- **共時的音韻規則（Synchronic: `→`）** と **通時的音変化（Diachronic: `>` / 再建形 `*p > b`）** の両方に完全対応。
- ワンクリックでプレビュー・KaTeX数式コード・テキスト記法を相互変換。

### 4. 学術文献（SPE・Hayes）に基づく正統な弁別素性体系
- Chomsky & Halle (1968) *SPE*、Clements & Hume (1995)、Hayes (2009) に基づく標準的弁別素性をクイックパレットに網羅。
- 変項 $\alpha, \beta$ を用いた同化規則や、ユーザー定義のオリジナル素性を自由に作成・追加できるカスタム素性機能。

### 5. ピュアSVGによる高品質エクスポート
- **高解像度 PNG ダウンロード & クリップボード直接コピー**:
  論文やスライドにそのまま貼れるクリアなPNG（2x Retina解像度）。WordやPowerPointに直接ペースト可能。
- **ベクター SVG ダウンロード**:
  拡大しても粗くならない無限解像度ベクターファイル。
- **KaTeX / LaTeX コード生成**:
  Overleaf、Obsidian、各種Markdownでそのまま使える `amsmath` 準拠のクリーンな数式コードをワンクリックコピー。
- **フォント切り替え**:
  論文・学術誌向けの「明朝 / ローマン（Serif）」と、スライド・Web向けの「ゴシック / サンセリフ（Sans）」をワンクリックで選択可能。

### 6. 代表的な音韻規則プリセット
- 英語 弾音化 (Flapping: `t -> ɾ / [+syl, +stress] _ [+syl, -stress]`)
- 母音鼻音化 (Vowel Nasalization)
- 語末無声化 (Final Devoicing)
- 鼻音同化 (Nasal Place Assimilation)
- 日本語 口蓋化 (Palatalization)
- 母音脱落 (Syncope / Deletion)
- グリムの法則 (Grimm's Law: `*p > f / # _`)
- 母音間有声化 (Intervocalic Voicing: `*p > b / V _ V`)
- 第二次子音推移 (High German Shift: `*t > ts / # _`)

## 📖 記法リファレンス (Syntax Guide)

| 記法 | 入力例 | 説明 |
| :--- | :--- | :--- |
| **素性行列** | `[+syl, +high]` | 角括弧内にカンマまたはスペース区切りで素性を列挙 |
| **音素・文字** | `k`, `t`, `ɾ` | 直接英数字やIPA文字を入力 |
| **共時的規則** | `A -> B / C _ D` | 矢印 `->` または `→` で変化 |
| **通時的音変化** | `A > B / C _ D` | 大なり不等号 `>` で変化（再建形: `*p > b`） |
| **境界記号** | `#`, `$`, `+` | `#`（語境界）、`$`（音節境界） |
| **脱落・ゼロ** | `∅`, `0`, `null` | 自動的にゼロ記号（`∅`）に変換 |
| **環境下線** | `_` または `__` | 標的音が現れる位置を指定 |
| **文脈自由規則** | `k -> t` | 環境 `/` を省略すると文脈自由規則として生成 |

## 🚀 使い方

1. `index.html` を任意のWebブラウザで開きます。
2. キーボードでテキストを直接入力するか、スロットをクリックしてパレットから素性を追加します。
3. 必要に応じて「`→`」と「`>`」をワンクリックで切り替えます。
4. 「PNG コピー」または「KaTeX コピー」を押して、レポートや発表スライドに貼り付けます。
5. 操作に迷った時は <kbd>?</kbd> キーまたは右上の `HELP [?]` を押すとクイックガイドが表示されます。
